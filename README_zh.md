✅ 按你的标准自动扫描候选人列表，逐个判断是否符合  
✅ 不符合的直接跳过，符合的自动打招呼  
✅ 打完招呼立刻追发索材消息，不用你再操心  
✅ 遇到拿不准的边界情况，暂停来问你  
✅ 定时汇报进度，已联系的不重复接触  
✅ 适用 BOSS直聘、猎聘、智联招聘、拉勾等主流平台
